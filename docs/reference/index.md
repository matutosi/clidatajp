# Package index

## Climate data of the world

Download links and climate data from ‘JMA’ web pages.

- [`download_area_links()`](https://matutosi.github.io/clidatajp/reference/download_links.md)
  [`download_links()`](https://matutosi.github.io/clidatajp/reference/download_links.md)
  : Download links for areas, countries and stations
- [`download_climate()`](https://matutosi.github.io/clidatajp/reference/download_climate.md)
  : Download climate data of the world
- [`clean_station()`](https://matutosi.github.io/clidatajp/reference/clean_station.md)
  : Clean up station information

## Detail climate data in Japan

Yearly, monthly, daily, hourly and 10 minutes values of each station.

- [`detail_url()`](https://matutosi.github.io/clidatajp/reference/detail_url.md)
  [`detail_item()`](https://matutosi.github.io/clidatajp/reference/detail_url.md)
  : Build urls of detail climate data in Japan
- [`download_detail()`](https://matutosi.github.io/clidatajp/reference/download_detail.md)
  : Download detail climate data in Japan
- [`download_prec_no()`](https://matutosi.github.io/clidatajp/reference/download_prec_no.md)
  [`download_block_no()`](https://matutosi.github.io/clidatajp/reference/download_prec_no.md)
  : Download prec_no and block_no of stations in Japan
- [`detail_colnames()`](https://matutosi.github.io/clidatajp/reference/detail_colnames.md)
  [`clean_detail_value()`](https://matutosi.github.io/clidatajp/reference/detail_colnames.md)
  [`to_numeric_when_all()`](https://matutosi.github.io/clidatajp/reference/detail_colnames.md)
  : Helper functions for download_detail()
